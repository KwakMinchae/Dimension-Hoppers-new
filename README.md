# README tldr
Dimension Hoppers is a Unity game built in C# that blends two genres across alternating dimensions. 
Players start in a 2D card game, earning points and items before a timer triggers a dimension shift into a 3D arena, 
where those items are used to fight a dragon. 
The cycle repeats until the player dies.
